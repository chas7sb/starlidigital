# Native company Facebook/Instagram UI

`CompanySocialConnections.svelte`: props companyId, actorId, conversationId, accessSignal; optional companyName and platform (`facebook`, `instagram`, `both`). Events close, denied {status}, changed {companyId}. This is reusable in canonical chat and Apps/panels. Root owns mounting/navigation.

Transport uses only `/api/v1/starli/companies/{company}/social` with native session bearer, same-origin/no-store, version `starli.company-social.v1`, exact company and late-session/access fencing. Frozen backend contract/source was reviewed in `work/company-social-native/starli_company_social/core.py`: GET connections and account-assets; POST connect and delegations; DELETE delegations/{id} with expectedRevision. Delegation responses use envelope.delegation; revocation returns a scoped partial receipt.

An existing personal account is never automatically granted to a company. Assets are requested only when ownedByCurrentUser, ownerUserId===actorId and canDelegate all permit it. Facebook Pages and linked Instagram destinations come from fresh native account-assets. Human review lists the exact destinations and requires an explicit company-access checkbox. The response must match selected Page/connection/Instagram IDs. Revoke is confirmed separately and retains the personal connection. OAuth/client/node publishing readiness flags remain separate; CLIENT_NOT_CONFIGURED and publishingReady=false are shown honestly, with no app-secret input or fake working publish controls.

Canonical helper `socialConnectionSelection(message, roomId, companyId)` accepts only `message.data.starliSocial` whose version/company/source room/assistant message/requesting bot match the already native-authorized message. Metadata is a lookup hint, never authority. Native tool company_social_connect prepares only that current-message card; it does not start OAuth.

The existing frontend callback route accepts provider `social` and renders `CompanySocialOAuthCallback.svelte`. It reads only an opaque #handoff fragment, scrubs fragment/query before native POST `/api/v1/starli/social/oauth/complete {handoff}`, and never accepts raw OAuth codes/state. The verified result connects the personal account only. The return button navigates to the server-returned original company conversation to review Page/Instagram delegation. No company permission is silently created by the callback.
