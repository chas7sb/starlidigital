# Linux runtime service templates

These templates describe the additional services inside the isolated Linux runtime. Replace `@EXTENSIONS_ROOT@`, `@NODE@`, `@PYTHON@`, `@PRIVATE_ENV@`, `@USER@`, and `@PRIVATE_STATE@` before installing. They are not enabled automatically. The environment file is generated by local setup; no production environment file is reused. Keep application listeners on loopback and use the application gateway for browser access.

See `../service-contracts.json` for required enrollment, configuration and build prerequisites. A template existing does not mean the capability is configured. Run these with an unprivileged runtime account. Platform and dashboard services are owned by the base installer.
